# 통신 프로토콜 (M400 실기 ↔ 키오스크 PC)

시뮬레이터는 아래 바이트 프로토콜을 그대로 구현합니다. 원본 키오스크 앱의 `controller/serial/**` 코드를 분석해 재구성했으며, 원본 코드를 수정 없이 연결해 검증했습니다 (`examples/legacy-app-check.cjs`).

| 장치 | 실기 포트 | 시뮬레이터 TCP | 형식 |
|---|---|---|---|
| 메인보드 (커피머신) | COM1, 38400 8N1 | 127.0.0.1:7001 | ASCII 프레임, 국번 `01` |
| 제빙기 | COM2, 9600 8N1 | 127.0.0.1:7002 | 7바이트 바이너리 |
| 컵 디스펜서 | COM3, 9600 8N1 | 127.0.0.1:7003 | ASCII 프레임, 국번 `02` |
| 카드 단말기 (KSCAT 에이전트) | HTTP 127.0.0.1:27098 | 같음 | JSONP, `REQ=` 전문 |

## 1. 메인보드 / 컵 디스펜서 ASCII 프레임

```
요청   ENQ(05) ID(2) CMD(2) ADDR(4) LEN(3) [DATA(LEN)] EOT(04) SUM(2)
         CMD: "BW" 쓰기(S 영역) / "BR" 읽기(M 영역)
         예) 05 '01' 'BW' 'S000' '001' '1' 04 'A7'      메뉴모드 ON
             05 '01' 'BR' 'M000' '149' 04 '..'          상태 149바이트 읽기
ACK    메인보드  ACK(06) ID CMD ADDR(4) ETX(03) SUM(2)          12바이트
       컵        ACK(06) ID CMD NUM(3) SUM(2)                   10바이트
NAK    메인보드  NAK(15) ID CMD ADDR(4) ERR(2) ETX SUM          14바이트
       컵        NAK(15) ID CMD ERR(3) SUM                      10바이트
읽기응답 STX(02) ID CMD ADDR(4) LEN(3) DATA(LEN) ETX(03) SUM(2)   15+LEN 바이트
```

- `SUM` = 앞 모든 바이트 합의 하위 1바이트를 16진 ASCII 2글자로 (`0x4C` → `'4','C'`)
- `DATA`는 바이트 단위입니다. 플래그는 ASCII `'0'/'1'/'2'`, 온도·레시피 레지스터는 **raw 바이트**
- 원본 앱의 `setCupSensor()`는 주소를 3글자(`'007'`)로 보내는데, 실기와 시뮬레이터 모두 `S007`로 해석합니다
- 읽기 응답에서 `M[i]`는 프레임의 `12 + i` 번째 바이트입니다 (원본 코드의 `message[12 + i]`)

### 1.1 메뉴 명령의 핸드셰이크

```
호스트: BW S153 '1'          (커피 추출 명령)
장치  : ACK                  M111 = '1' (동작 중)
호스트: BR M000 140 반복      M111 == '2' 가 될 때까지 (완료)
...  (다음 명령들)
호스트: BW S150 '000000000000000'   (Clear15: S150~S164 모두 '0')
호스트: BW S168 '00000'             (Clear05: S168~S172)
장치  : 해당 M 값 '0' 으로 복귀
```

## 2. 제빙기 (7바이트)

```
STX(02) STATUS(01) CMD D1 D2 CHECK(STATUS^CMD^D1^D2) ETX(03)
```

| CMD | 의미 | D1 / D2 |
|---|---|---|
| B0 | 출빙 명령 (대기 → 컵 레버가 눌리면 출빙) | 얼음 시간 / 물 시간, 0x55 = 5.5초 |
| CF | 상태 조회 | 응답 D1, D2 (아래) |
| A0 | 통신모드, 컵 이탈 무시 | 01 / 01 |
| D0 | 출빙 대기 타임아웃 | 분 / 초 |
| E0 | 재부팅 | |

응답 D1 비트 (MSB부터): 만빙, 통신모드, 컵레버, 출빙 SOL, 기어모터, 컴프레서, 직전 얼음 감지, 직전 얼음 미감지
응답 D2: bit4(0x10) = `1` 출빙 명령 대기 / `0` 출빙 완료·타임아웃, 하위 4비트 = 에러코드 (E1 급수 부적합 … EF 팬모터)

## 3. 카드 단말기 (KSCAT 에이전트)

키오스크는 `http://127.0.0.1:27098` 에 jQuery JSONP 로 `REQ=<전문>` 을 보냅니다.

- 승인: `"AP" + 길이(4) + STX + "IC" + "01" + "0200" + ... + FS + 할부(2) + 금액(12) ...` (KSCatAppr)
- 취소: 전문구분 `0420`, 바코드 결제: 거래구분 `PC`(카카오) / `MI`(네이버)
- 카드 회수 확인: `AP` + STX + `0007S4   ` → `{STATUS: 'INS' | 'DEL'}`
- 응답 JSON 주요 필드: `RES`('0000' 성공), `STATUS`('O' 정상, 'X'), `APPROVALNO`, `TRADETIME`, `TERMID`, `MESSAGE1/2`

시뮬레이터에서는 승인 요청이 오면 3D 카드 단말기가 깜빡이며 카드를 넣을 때까지 기다립니다. 승인 후 카드를 빼기 전까지 `S4` 조회는 `INS` 를 돌려줍니다.
